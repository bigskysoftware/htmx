### Request Methods

- [htmx.ajax()](/reference/methods/htmx-ajax) - issues an htmx request

### DOM

- [htmx.find()](/reference/methods/htmx-find) - finds first matching element
- [htmx.findAll()](/reference/methods/htmx-findAll) - finds all matching elements
- [htmx.process()](/reference/methods/htmx-process) - processes htmx attributes on element
- [htmx.swap()](/reference/methods/htmx-swap) - swaps HTML content
- [htmx.initialize()](/reference/methods/htmx-initialize) - manually initializes htmx

### Event Handling

- [htmx.on()](/reference/methods/htmx-on) - listens for htmx events
- [htmx.onLoad()](/reference/methods/htmx-onLoad) - executes callback when elements load
- [htmx.trigger()](/reference/methods/htmx-trigger) - triggers custom events

### Extensions

- [htmx.registerExtension()](/reference/methods/htmx-registerExtension) - registers htmx extension

### Timing

- [htmx.parseInterval()](/reference/methods/htmx-parseInterval) - parses time intervals to milliseconds
- [htmx.timeout()](/reference/methods/htmx-timeout) - creates timeout `Promise`
