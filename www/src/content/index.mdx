htmx is a small library that adds a few [attributes](/reference/attributes) to HTML, transforming the hypertext you know
& love into a modern, dynamic tool that you can build amazing websites with.

## An Example

```html
<button hx-post="/clicked" hx-swap="outerHTML">
    Click Me
</button>
```

When this button is clicked, the [`hx-post`](/reference/attributes/hx-post) attribute tells htmx to send a `POST` to
`/clicked` and the [`hx-swap`](/reference/attributes/hx-swap) attribute tells htmx to replace the button with the response's HTML.
